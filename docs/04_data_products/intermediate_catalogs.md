# Intermediate Catalogs

During execution, FORECAST produces intermediate data products that bridge the pipeline stages.

---

## 1. `planes_list.txt` (Master Plane Geometry)
Generated by `lc` on startup. Contains the cosmological geometry for every lightcone slice.

| Col # | Field Name | Type | Description | Units |
| :---: | :--- | :---: | :--- | :--- |
| 1 | `plane_index` | `int` | Sequential 1-based plane index ($1, \dots, N$) | dimensionless |
| 2 | `z_plane` | `float` | Central slice redshift $z_i$ | dimensionless |
| 3 | `D_c1` | `float` | Near comoving distance boundary | $\text{cMpc} / h$ |
| 4 | `D_c2` | `float` | Far comoving distance boundary | $\text{cMpc} / h$ |
| 5 | `replica_idx` | `int` | Plane replica index within snapshot (0-indexed) | dimensionless |
| 6 | `snapshot_num` | `int` | Simulation snapshot number | dimensionless |
| 7 | `z_nominal_snap` | `float` | Nominal snapshot cosmological redshift | dimensionless |

---

## 2. `coords.lc.<snap>_<plane>.txt` (LC Output $\to$ DF Input)
ASCII table containing all star particles inside the field of view for that slice.

| Col # | Field Name | Type | Description | Units |
| :---: | :--- | :---: | :--- | :--- |
| 1 | `subhalo_id` | `int` | Subhalo ID (-1 for unbound fuzz) | dimensionless |
| 2 | `x_proj` | `float` | Angular FoV X coordinate | normalized |
| 3 | `y_proj` | `float` | Angular FoV Y coordinate | normalized |
| 4 | `redshift` | `float` | Line-of-sight redshift $z_{\text{los}}$ | dimensionless |
| 5 | `mass` | `float` | Current stellar mass $M_*$ | $10^{10} M_\odot / h$ |
| 6 | `init_mass` | `float` | Initial stellar birth mass $M_{*,\text{init}}$ | $10^{10} M_\odot / h$ |
| 7 | `metallicity` | `double` | Stellar metallicity $Z_*$ | mass fraction |
| 8 | `CM_z` | `float` | Subhalo Center of Mass Z coordinate | $\text{ckpc} / h$ |
| 9 | `age` | `float` | Stellar age $t_*$ | $\text{Gyr}$ |
| 10 | `x_orig` | `float` | Original unrotated box X | $\text{ckpc} / h$ |
| 11 | `y_orig` | `float` | Original unrotated box Y | $\text{ckpc} / h$ |
| 12 | `N_sim` | `double` | Total particles in parent subhalo | count |

---

## 3. `flux.df.<snap>_<plane>.txt` (DF Output $\to$ DC Input)
- **Columns 1–10**: Metadata identical to `coords.lc` (`subhalo_id`, `x`, `y`, `z`, `mass`, `init_mass`, `metallicity`, `CM_z`, `age`, `N_sim`).
- **Columns 11 to $10 + N_{\text{filters}}$**: Dust-free stellar fluxes $f_{\text{df}, 1}, \dots, f_{\text{df}, N}$ in microjanskys ($\mu\text{Jy}$).
